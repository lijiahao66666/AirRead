# AirRead（灵阅）

AirRead 是一个本地优先的沉浸式双语阅读器。用户可以在浏览器中导入自己的 EPUB/TXT，阅读时实时翻译，也可以在书籍工作室中处理和导出电子书。

## 推荐使用方式

```bash
cd pwa
npm install
npm run dev
```

构建生产版本：

```bash
cd pwa
npm run build
```

将 `pwa/dist/` 部署到任意静态托管即可。托管服务需要提供静态文件，并将未知路径回退到 `index.html`。

更完整的运行、部署、BYOK 和隐私说明见 [`pwa/README.md`](pwa/README.md)。

## 产品能力

- **书架与阅读器**：支持 EPUB 2/3、UTF-8/GBK/GB18030 TXT、章节目录、进度记忆、选中文本实时翻译、失败重试。
- **书籍工作室**：作为可扩展的本地工具中心；目前已提供双语书制作，界面中明确列出 TXT 转 EPUB、EPUB 格式整理等后续方向。
- **制作双语书**：提供整本 EPUB 的顺序翻译、暂停/恢复、失败段落重试、双语或仅译文导出。
- **两种翻译体验**：阅读器提供即时的选中文本翻译，工作室提供可暂停、可重试、可导出的整书处理流程；两者共享翻译服务配置与缓存。
- **免费 + BYOK**：内置免费翻译用于开箱体验；用户也可自行填写 OpenAI-compatible、Azure Translator 或腾讯云 TMT 的地址、区域和 API Key。
- **本地优先**：书籍、进度、翻译缓存和翻译服务配置保存在当前浏览器，打开网页即可使用。

## 翻译与跨域说明

AirRead 默认提供免费翻译，也支持配置自己的翻译服务。翻译请求由浏览器直接发送到所选服务，API Key 保存在当前浏览器。第三方接口需要允许当前站点的 CORS；如果浏览器提示无法连接，应开启对应服务的网页访问能力、更换支持浏览器直连的地址，或在自己的设备上运行中转服务。腾讯云 TMT 是否允许浏览器直连，以腾讯云接口的实际 CORS 策略为准。

免费翻译服务的可用性和配额由第三方决定，重要书籍建议配置自己的 Provider，并在导出前抽样校对译文。
