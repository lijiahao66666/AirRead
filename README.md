# AirRead 英语学习

AirRead 是一个本地优先的英语学习 PWA。它不要求用户设置多个学习目标：目标固定为听懂真实英语、自然交流、阅读常见英文内容，并逐步具备英语考试能力。用户只需要设置每天可用的分钟数，系统据此安排当天的输入、回忆、跟读和复习。

## 当前能力

- **原创连载**：用户可以输入一个大概设定，也可以留空让 AI 自选题材。每天生成同一故事的下一章，并关联前情回顾、英文正文、中文译文、词块、阅读检测、听力、跟读、复述和写作；每章英文词数可在设置中按 80–2,000 词调整。当前章节生成后，下一章会在后台提前准备，学完后可直接开始。
- **长期故事记忆**：不会把整部小说反复塞进模型上下文，而是维护故事圣经、世界规则、人物当前状态、压缩时间线、未解线索、上一章摘要和结尾钩子。每章只读取这份受长度限制的记忆，生成后再校验并更新它。
- **科学复习**：只有完成当天学习包后，新词块才进入间隔重复队列；复习时先主动回忆，再确认是否记住，以调整下次间隔。
- **学习计划**：自动生成未来 7 天的主题与训练重点；改变每日时长会同步更新计划和当天内容预算。完成当天学习后，可以直接继续生成下一章。
- **音频规则**：AI 原创章节没有“原版音频”，只能使用设备系统朗读辅助；不会把合成语音冒充真人录音，也不会要求模型生成 TTS。
- **用户模型**：可配置 OpenAI Chat Completions 兼容协议、OpenAI Responses API 或 Anthropic Messages API。配置模型后才会生成中文译文、词块和个性化任务；API Key 只保存在当前浏览器，AirRead 不提供官方模型额度，也不代为转发请求。
- **本地存档**：学习状态会保存到当前浏览器；设置页可先选择一个 EPUB 文件开启连续存档，之后新章节自动更新该文件，并在连接后提供“导出 EPUB”。不支持文件系统权限的浏览器无法自动更新文件，请使用支持文件访问的 Chrome/安卓浏览器。
- **模型请求**：章节生成请求最长等待 10 分钟，避免较长章节在正常生成过程中被过早中断。

## 内容来源原则

学习材料全部是 AI 原创连载，不抓取、翻译或续写《夜无疆》等版权小说，也不使用外部小说人物、情节或作者风格。模型请求由用户在浏览器中配置的服务直接完成；没有可用模型时不会偷偷回退到固定文章或公共资料。

## 本地运行

```bash
npm install
npm run dev
```

验证：

```bash
npm test -- --run
npm run build
```

构建产物位于 `dist/`，可部署到任何支持 SPA 回退的静态托管服务。腾讯云 Lighthouse 的原子发布流程见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 项目结构

```text
AirRead/
├── public/               # PWA 图标、清单与 Service Worker
├── scripts/              # 本地打包与服务器原子发布脚本
├── src/domain/ai/        # 三种 LLM 协议与模型配置存储
├── src/domain/learning/  # 学习计划、学习包、复习状态与生成器
├── src/features/learning/ # 今日学习、计划、复习和设置页面
└── src/pwa/              # PWA 安装提示与缓存策略
```
