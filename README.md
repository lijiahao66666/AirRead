# AirRead 英语学习

AirRead 是一个本地优先的英语学习 PWA。它不要求用户设置多个学习目标：目标固定为听懂真实英语、自然交流、阅读常见英文内容，并逐步具备英语考试能力。用户只需要设置每天可用的分钟数，系统据此安排当天的输入、回忆、跟读和复习。

## 当前能力

- **每日学习包**：只根据可用时间准备英文材料、中文解释、词块和可执行训练任务；5 分钟也会得到完整的“输入 → 回忆/输出”最小闭环，不会被拆成无法执行的残余任务。
- **科学复习**：只有完成当天学习包后，新词块才进入间隔重复队列；复习时先主动回忆，再确认是否记住，以调整下次间隔。
- **学习计划**：自动生成未来 7 天的主题与训练重点；改变每日时长会同步更新计划和当天内容预算。
- **音频规则**：资料本身有原版录音，且同时提供 HTTPS 音频地址、来源地址和授权信息时才播放原音并显示来源；其他情况只能使用设备系统朗读辅助，不会把合成语音冒充原版音频。
- **自带模型**：可配置 OpenAI Chat Completions 兼容协议、OpenAI Responses API 或 Anthropic Messages API。API Key 只保存在当前浏览器，AirRead 不提供官方模型额度，也不代为转发请求。
- **离线优先**：学习计划、学习包、完成记录和复习队列保存到当前浏览器；Service Worker 缓存应用壳和静态资源，便于安装为 PWA 后使用。

## 内容来源原则

AI 负责制定计划、生成练习和调整难度。外部资料只有在来源、链接和授权信息可保留时才可作为学习材料；需要原版音频的内容必须带有其原始录音链接。当前版本已支持模型返回并校验这组来源元数据，但没有默认抓取任意网页；GitHub 文档、开放许可 RSS、Wikimedia Commons、LibriVox 等会通过独立来源适配器接入，不直接抓取或托管授权不明确的内容。

## 本地运行

```bash
npm install
npm run dev
```

验证：

```bash
npm test -- --run
npm run build
```

构建产物位于 `dist/`，可部署到任何支持 SPA 回退的静态托管服务。腾讯云 Lighthouse 的原子发布流程见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 项目结构

```text
AirRead/
├── public/               # PWA 图标、清单与 Service Worker
├── scripts/              # 本地打包与服务器原子发布脚本
├── src/domain/ai/        # 三种 LLM 协议与模型配置存储
├── src/domain/learning/  # 学习计划、学习包、复习状态与生成器
├── src/features/learning/ # 今日学习、计划、复习和设置页面
└── src/pwa/              # PWA 安装提示与缓存策略
```
